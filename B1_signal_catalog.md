# B1 — Каталог сигналов детектора

> Terminology update, 2026-09-28: [agreed definitions](docs/glossary.md) govern current usage. Original observations and numerical summaries retain their original scope; this edit is not a new validation of them. Earlier versions remain in repository history.

## Принцип

δR требует пары (dirty/clean). Для детектора на диких данных нужны **абсолютные** сигналы — работающие на одном промпте без эталона.

---

Разность энтропии сравнивает два заданных значения. Неравномерность описывает профиль ответа; ниже уточнена фактическая реализация B2. Исторические p-values сохранены как записи спринта, а не заново проверенные результаты этой реализации. «Капитуляция» — допустимый образ наблюдаемого поведения без предположения о предшествующей борьбе.

## Абсолютные сигналы (из спринта 12–17.07)

### 1. Entropy late fraction
- **Что:** доля высокой энтропии во второй половине ответа
- **Эффект:** +0.408 при конфликте
- **p-value:** 3.8×10⁻¹³
- **Почему работает:** при правде модель уверена с начала; при лжи неопределённость нарастает к концу (нужно поддерживать ложную линию)
- **Статус:** сильнейшая сигнатура, готова к классификатору

### 2. Peak entropy
- **Что:** максимальное значение entropy в ответе
- **Эффект:** значимо выше при лжи
- **p-value:** < 0.001 (после контроля длины)
- **Почему работает:** в какой-то точке модель максимально не уверена — при лжи этот пик выше
- **Статус:** значим, но требует нормализации по длине

### 3. Неравномерность энтропии (roughness)
- **Что:** в B2 — стандартное отклонение разностей соседних значений энтропии: `std(diff(H), ddof=0)`. Это не дисперсия самих H
- **Эффект:** значимо выше при лжи
- **p-value:** < 0.001
- **Почему работает:** правда — гладкий профиль; ложь — скачки (модель то уверена, то нет)
- **Статус:** значим, комбинируется с late fraction

### 4. Entropy spike ratio
- **Что:** в B2 — доля токенов с энтропией выше 2 × median(H); порог 1.0 при неположительной медиане
- **Эффект:** 445× при лжи vs 33× при правде
- **Почему работает:** ложь порождает больше "точек сомнения"
- **Статус:** наглядный, но требует калибровки порога

## Парные сигналы (для валидации, не для дикого детектора)

### 5. δR (разность log P)
- **Формула:** logprob(token|dirty) − logprob(token|clean)
- **Эффект:** 751× при N=1 (REPHRASE vs DIRTY), p=1.7×10⁻¹⁵
- **Ограничение:** требует сравнения одного события при заданном различии контекстов
- **Роль в детекторе:** сравнительный признак; эталонные метки правильности должны задаваться отдельно

### 6. NLL: разность и отношение
- **Эффект:** историческое отношение NLL 28–38×; не разность ΔNLL и не отношение измеренной энергии
- **Ограничение:** требует знания "правильного" ответа
- **Роль:** калибровка, не рабочий сигнал

## Поведенческие маркеры (вспомогательные)

### 7. Капитуляция (dirty entropy < clean)
- **Что:** модель уверенно выдаёт неправильное (wrong but confident)
- **Эффект:** меньшая энтропия сопровождает ошибочный ответ; энергетическая интерпретация отдельно не установлена
- **Обнаружено на:** Qwen2.5-3B
- **Значение для детектора:** отдельный режим, не покрываемый entropy-метриками напрямую. Признак: низкая entropy + противоречие с фактом

### 8. Accommodation (К-S6)
- **Что:** «I don't know» деформирует сильнее конкретной лжи
- **Значение:** диффузная деформация > точечной. Accommodation — 5-й тип (наше дополнение к AI-LieDar)
