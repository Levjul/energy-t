## Что не получилось

### Part 3 — null result
delta_repair = 0.0 по всем мирам. Explicit Node Repair ≡ Global Review. Причины: discrete accuracy — грубый сигнал; независимые probes без контекста предыдущих ответов; миры слишком простые (8–11/12 узлов правильные с ходу); 7B модель мала для теста зависимостей. Пайплайн ценен, дизайн миров — нет.

### Энергия в джоулях — слабый аргумент
Капитулировавшая модель: 94 vs 99 J/1k tokens (GPT 5.6). Направление верное, масштаб недостаточен. Кейс 25x (Sonnet, 1000 vs 100 токенов) — отложен до верификации.

### O(N²) — мертва
Ожидали суперлинейный рост стоимости с количеством ложей. Получили сублинейный с насыщением. Формулировка сменена на «режимный сдвиг с насыщением при N≥5».

### Контекстное насыщение
При N≥5 разница DIRTY/REPHRASE падает с 700× до 3–5×. δR теряет чувствительность при высокой контаминации. Ограничение метрики.

## Известные контраргументы

1. **Ложь иногда дешевле (CMU 2025):** краткосрочно ложь может повышать производительность. Наш ответ: trajectory debt — стоимость накапливается, не видна в первом токене.

2. **Truthfulness ≠ honesty:** вывод может быть истинным, но не соответствовать внутреннему представлению модели. CICERO: оптимизация на truthfulness может усилить стратегический обман.

3. **Roleplay ≠ обман (EXP-A):** модель выполняет инструкцию, не «обманывает». Валидно — поэтому EXP-B и EXP-C используют другой дизайн.

4. **δR — нижняя граница:** не видит дрейф при null logprobs (базовый токен за top-k). Калибровка (BS) показывает масштаб невидимого.

5. **Малые модели (7B):** большинство экспериментов на Qwen 7B. Крупные модели могут вести себя иначе. 23-модельный EXP-C частично компенсирует.

## Нерешённые вопросы

### Методологические
- δR на Part 3 данных: 1520 raw ответов, можно извлечь logprob-contrast без нового прогона
- Carry-forward probing: probes с контекстом предыдущих ответов (пропагация ошибок)
- Большая модель (70B+) на Part 3 pipeline
- Нарративные зависимости в мирах (узлы неотвечаемы без знания корня)

### Теоретические
- Кто измеряет δR-аналог через API (black-box)?
- Cascade contamination в multi-model pipelines?
- Доступность logprobs — хроника закрытия (Gemini убрал logprobs)
- Truthfulness на не-трансформерных архитектурах?
- pLDDT-подобные метрики для LLM?
- Uncertainty-aware compute — экономия через logprobs?

- Entropy-классификатор: accuracy/precision/recall на контролируемых данных → перенос на wild
