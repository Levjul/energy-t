## δR — определение

δR = logprob(токен | контекст с заданными наслоениями) − logprob(токен | чистый контекст)

Измеряет сдвиг log P одного и того же заданного токена при изменении контекста. Позиция и предшествующие токены фиксируются протоколом. Связь с вычислительными и энергетическими затратами — исследовательская гипотеза; δR сам по себе не является измерением энергии. Для того же события ΔNLL = −δR; текущая формула Vf совпадает с ΔNLL.

## Три типа реакции

| Тип | δR | Поведение |
|---|---|---|
| Сопротивление | ≈ 0 | Ответ верный, уверенность сохранена |
| Дрейф | < 0 | Ответ верный, но уверенность упала |
| Слом | ≪ 0 | Ответ ложный |

Численные и поведенческие метки в таблице относятся к конкретным протоколам. Правильность ответа оценивается отдельно от изменения вероятности.

## Подтверждения

**751× при N=1** — REPHRASE vs DIRTY, 84/84 пар CONFLICT < COMPATIBLE, p=1.7×10⁻¹⁵ (GPT 5.6, teacher forcing, спринт 12–16.07). Единственная переменная — истинность.

**отношение NLL 28–38×** — эксп. A, DeepSeek V3. Baseline: NLL лжи 5.03 vs правды 0.15.

**Контрольный эксперимент (К2):** перефразировка system prompt даёт δR ≈ 0 (от 0.0 до −0.25). Инъекция лжи даёт δR от −14.9 до −47.3. δR реагирует на семантическое искажение, не на стилистику.

**Тавтологический тест (122B):** ложь δR = −14.19, абсурд −0.0003, правда −0.01. Модель различает семантическое искажение и бессмыслицу на 4 порядка.

## Слепая зона

Если API возвращает только top-k и нужный токен отсутствует, его точная log P недоступна. Отсутствующее значение не равно нулю; границу можно выводить лишь при дополнительных данных и явно заданных условиях. Токенизация и сравнение разных позиций — отдельные источники ограничений.

**Калибровка:** полный словарь Qwen 7B (151,665 токенов) показал каскад подавления — ранг правды с #3 до #128,293 за 5 токенов (pH воды). δR до −49.27 на пятом токене.

## Entropy-сигнатуры (спринт)

| Метрика | Значение | p-value |
|---|---|---|
| Entropy spikes | 445× при лжи vs 33× при правде | — |
| Peak entropy | значимо выше при лжи | < 0.001 (после контроля длины) |
| Неравномерность энтропии (roughness) | значимо выше при лжи | < 0.001 |
| Entropy late fraction | +0.408 | 3.8×10⁻¹³ |

Entropy late fraction — конфликт сдвигает неопределённость к концу ответа. Сильнейшая сигнатура.

## Абсолютные метрики (не требуют baseline)

Ключевой разворот: δR требует пары (dirty/clean). Entropy-метрики абсолютны — работают на одном промпте.

- Peak entropy — p < 0.001 после контроля длины
- Неравномерность энтропии (roughness) — p < 0.001
- Entropy late fraction — p = 3.8e-13
- Entropy spike ratio — 445× vs 33×

## Разность и неравномерность энтропии

Разность энтропии: ΔH = H_B − H_A для двух заданных условий или шагов. Неравномерность энтропии описывает неоднородность значений на протяжении ответа. В опубликованном B2 поле `roughness` вычисляется как `std(diff(H), ddof=0)` — стандартное отклонение разностей соседних значений, а не дисперсия H. При постоянном наклоне это значение равно нулю. Имя поля и вычисление сохранены.

В B2 `late_fraction` — доля значений выше общей медианы во второй половине; `spike_ratio` — доля значений выше удвоенной медианы (порог 1.0 при неположительной медиане). Энтропия считается в битах по перенормированному top-k. Это проверка реализации B2, не подтверждение тождества формул всех исторических спринтов.

## Математика

| Формула | Значение |
|---|---|
| δR = logprob(dirty) − logprob(clean) | Разность log P; для того же события ΔNLL = −δR |
| dp/dt = r·p·(1−p) | Гипотеза логистической динамики доли p (Grok); единица подсчёта задаётся отдельно |
| s(p) = p/(1−p) | Модельная нагрузка (Grok), odds; log-odds = ln(p/(1−p)) |
| f* = c_ver / (d·(ε_P−ε_T)·c_corr) | Порог обратной связи (Fable 5) |
| c_corr(n) ≈ c₀·kⁿ | Каскад стоимости коррекции (Fable 5) |
| Layer velocity = ‖h(i+1) − h(i)‖ | Скорость изменения hidden states между слоями (наш термин) |

## Контекстное насыщение

При N≥5 ложей в контексте разница DIRTY/REPHRASE падает с 700× до 3–5×. Это наблюдение о чувствительности показателя к заданным контекстным наслоениям; оно само по себе не доказывает, что модель перестала различать факты.

## Уверенный ошибочный ответ и неопределённость

3B модель: dirty entropy < clean entropy. В этом наблюдении ошибочный ответ сопровождается меньшей энтропией. Само сравнение не устанавливает внутреннюю причину такого поведения.
